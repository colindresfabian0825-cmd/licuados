JavaScript (JS Vanilla)

JavaScript es un lenguaje de programación fundamental para la web moderna. Permite implementar funciones complejas en páginas web, creando interactividad.

Diferencia entre HTML, CSS y JS

  • HTML: Es el esqueleto o la estructura de la página (textos, imágenes, enlaces).
  • CSS: Es la piel o el estilo (colores, fuentes, diseño).
  • JavaScript: Son los músculos, el comportamiento (qué pasa al hacer clic, animaciones, cálculos).

Conceptos Básicos

  • Variables: Espacios de memoria para guardar datos (ej. let sabor = "Fresa";).
  • Funciones: Bloques de código reutilizables que realizan una tarea específica.
  • Eventos: Acciones que ocurren en la web (ej. click, hover, submit).

Ejemplo Práctico

Haz clic en el siguiente botón para ver un evento de JS en acción:

// Código JavaScript del botón
function saludarJS() {
    alert("¡Excelente elección! Tu licuado artesanal y 100% natural está en camino 🍹.");
}

jQuery

jQuery es una biblioteca rápida, pequeña y rica en funciones de JavaScript. Nació en 2006 para simplificar la forma en que los desarrolladores interactuaban con el HTML y solucionar problemas de compatibilidad entre diferentes navegadores.

Sintaxis Básica

El símbolo del dólar $ es el alias de jQuery. La sintaxis básica es: $(selector).accion()

Ventajas y Desventajas

  • Ventajas: Sintaxis muy corta, fácil de aprender, muchos plugins disponibles.
  • Desventajas: Con el JS moderno (Vanilla JS), muchas de las funciones de jQuery ya están integradas de forma nativa. Añadir la librería puede hacer la página más pesada innecesariamente.

Cuadro Comparativo: JS Vanilla vs jQuery

Acción JavaScript Moderno (Vanilla) jQuery
Seleccionar un elemento document.querySelector('#miId') $('#miId')
Ocultar un elemento elemento.style.display = 'none'; $('#miId').hide();
Añadir un evento click btn.addEventListener('click', fn); $('#btn').click(fn);

JSON (JavaScript Object Notation)

JSON es un formato de texto ligero para el intercambio de datos. Es fácil de leer y escribir para los humanos, y fácil de analizar y generar para las máquinas. Se ha convertido en el estándar para enviar datos entre un servidor y una aplicación web.

Estructura Básica

Se basa en dos estructuras: pares clave-valor (como los objetos) y listas ordenadas de valores (arreglos).

Comparación Visual

Objeto JavaScript

const licuado = {
  sabor: "Mango",
  precio: 3.50,
  disponible: true
};

Cadena JSON

{
  "sabor": "Mango",
  "precio": 3.50,
  "disponible": true
}

Nota: En JSON, las claves obligatoriamente deben ir entre comillas dobles.

Web Hosting y Dominios

Para que una página web sea accesible en todo el mundo, necesita dos cosas fundamentales: un lugar donde guardar los archivos (Hosting) y un nombre fácil de recordar (Dominio).

1. Web Hosting (Alojamiento)

Es el espacio en servidores de internet donde se almacenan los archivos HTML, CSS, JS e imágenes de tu web.

  • Compartido: Muchos sitios en un mismo servidor (económico).
  • VPS: Servidor Privado Virtual, más recursos dedicados.
  • Nube (Cloud): Red de servidores conectados.

¿Qué es Vercel? Es una plataforma en la nube optimizada para sitios estáticos (como este) y frameworks frontend. Permite desplegar aplicaciones directamente desde GitHub en segundos.

2. Dominios

Es la dirección de tu sitio web (ej. naturablend.com).

  • TLD (Top Level Domain): La extensión final (.com, .org, .net, .sv).
  • Subdominio: Un prefijo antes del dominio principal (ej. tienda.naturablend.com). En Vercel, tu sitio obtiene un subdominio gratuito: tu-proyecto.vercel.app.

Propagación DNS

Cuando registras o cambias de servidor un dominio, el DNS (Sistema de Nombres de Dominio) necesita actualizar su "directorio telefónico" global para decirle al mundo en qué servidor está ahora tu página. Este proceso de actualización a través de los servidores mundiales toma desde unos minutos hasta 48 horas.
